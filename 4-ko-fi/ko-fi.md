# Ko-fi : page de dons

1. Créer le compte : https://ko-fi.com (« Start a page »). Choisir un pseudo, par exemple `sablierpc`.
2. **Display name** : Sablier
3. **About** (à coller) :

> Je développe **Sablier**, un petit utilitaire Windows gratuit et open source pour éteindre et allumer son PC automatiquement (minuterie d'arrêt, programmes chaque semaine, allumage depuis la veille). Si Sablier vous rend service, un café m'aide à le faire évoluer : version anglaise, nouvelles fonctions, et peut-être un jour un certificat pour supprimer l'avertissement de Windows. Merci ☕
> Téléchargement : https://github.com/mario07teck-sys/Sablier

4. **Bouton « Sponsor » sur GitHub** : dans le dépôt, *Add file › Create new file*, nom `.github/FUNDING.yml`, contenu (remplacer le pseudo) :

```yaml
ko_fi: sablierpc
custom: ["https://TON-PSEUDO-ITCH.itch.io/sablier"]
```

Puis *Settings › General › Features* : cocher **Sponsorships**.
